# Anisha's Portfolio Website

A modern, responsive portfolio website built with HTML, Tailwind CSS, and JavaScript. Features a beautiful dark mode, smooth animations, and an intuitive user interface.

## Features

- 🌓 Dark/Light mode toggle
- 📱 Fully responsive design
- ✨ Smooth animations and transitions
- 🎨 Modern UI with Tailwind CSS
- 💻 Clean and maintainable code
- 🚀 Fast loading and performance

## Pages

- 🏠 Home - Introduction and quick links
- 👋 About - Personal information and skills
- 📄 Resume - Professional experience and education
- 💡 Skills - Technical skills and expertise
- 🚀 Projects - Portfolio of work
- ✉️ Contact - Get in touch form

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Google Fonts
- Font Awesome Icons

## Setup

1. Clone the repository:
```bash
git clone https://github.com/yourusername/anisha-portfolio.git
```

2. Open the project folder:
```bash
cd anisha-portfolio
```

3. Open `index.html` in your browser or use a local server:
```bash
python -m http.server 8000
```

4. Visit `http://localhost:8000` in your browser

## Customization

- Update the profile image in each HTML file
- Modify content in HTML files to match your information
- Adjust colors and styling in the Tailwind configuration
- Add or remove sections as needed
